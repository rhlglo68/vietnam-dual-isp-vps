先说清楚概念，免得被营销词绕晕。普通VPS默认分配的是数据中心（IDC）IP，这类IP段登记信息一目了然，云服务商、机房归属、ASN都能查到，平台风控库里基本都收录过。而"住宅IP"指的是这个IP段实际登记在电信运营商名下，是给普通家庭宽带用户用的号段，从IP归属上看和你家里插的光纤猫没有区别。

"双ISP"则是更进一步——同一个C段或者说同一批IP，背后同时挂靠两家运营商的网络资源，通常是为了提高线路的稳定性和IP池的干净程度，避免因为单一运营商的IP段被集中举报或者滥用而拖累账号权重。放在越南这个场景里，LisaHost使用的是越南本地"西贡邮电"（Saigon Postel，简称SPT）这家相对小众的宽带运营商的IP段，官方描述是"独家小众越南西贡邮电宽带运营商IP段"，卖点就是这批IP用得人少、干净度高，对TikTok这类对IP质量敏感的平台相对友好。
